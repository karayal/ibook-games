# Local web fonts

- Nunito variable normal, weights200–1000: [official Google Fonts source](https://github.com/google/fonts/tree/main/ofl/nunito), downloaded November11,2026. Distributed under the bundled `Nunito-OFL.txt`.
- Noto Sans Arabic variable normal, weights100–900: [official Google Fonts source](https://github.com/google/fonts/tree/main/ofl/notosansarabic), downloaded November11,2026. Distributed under the bundled `NotoSansArabic-OFL.txt`.

Files are unmodified official TTF distributions. `fonts.css` declares both families for local browser use.
